# Vision

What crunes is meant to be, and why it has this shape.

## Documents

* [Context runes](/vision/context-runes.md) - A rune is a small project-local command that answers a question about the project right now, written once and called identically by a person, an agent and CI.
* [Runes in any language](/vision/multi-runtime-runes.md) - A rune becomes a project-local mini-program written in whatever language suits it, with crunes owning discovery, invocation and documentation rather than the runtime the program runs in.
